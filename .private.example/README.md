# Private operator notes (template)

Copy this folder to `.private/` locally. The real `.private/` directory is gitignored and will not be pushed to GitHub.

Suggested files:

- `REPLICATION_NOTES.md` — Firestore replication glossary and admin document notes
- `ADMIN_SETUP.md` — how `/admins/{uid}` documents are created
- `INCIDENTS.md` — security or support incidents (no user PII in public issues)

Do not store service-account JSON files here; keep them outside the repository entirely.
